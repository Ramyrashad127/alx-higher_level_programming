# 0x09. Python - Everything is object

## Description
Deep exploration of Python object model: object identities (id), types (type), mutability vs immutability of built-in data types, variable aliasing, and memory allocation semantics.

## Learning Objectives
- Master higher-level language paradigms and architectural concepts.
- Follow PEP 8 style standards for Python and Semistandard for JavaScript.
- Build clean, modular, and testable code.
