# 0x12. JavaScript - Warm up

## Description
JavaScript fundamentals for backend developers: running scripts with Node.js, variable declarations (let, const), data types, conditional branching, loops, functions, and command-line argument handling.

## Learning Objectives
- Master higher-level language paradigms and architectural concepts.
- Follow PEP 8 style standards for Python and Semistandard for JavaScript.
- Build clean, modular, and testable code.
