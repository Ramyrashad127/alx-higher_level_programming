# 0x0F. Python - Object-relational mapping

## Description
Connecting Python applications to MySQL databases: using MySQLdb to execute raw SQL, and leveraging SQLAlchemy ORM to map Python models to relational database tables, executing queries, and managing relationships.

## Learning Objectives
- Master higher-level language paradigms and architectural concepts.
- Follow PEP 8 style standards for Python and Semistandard for JavaScript.
- Build clean, modular, and testable code.
