This repository contains the higher-level programming curriculum for the **ALX Software Engineering Program**. It bridges foundational computer science with high-level languages and data layers, emphasizing **Python Object-Oriented Programming (OOP)**, **Test-Driven Development (TDD)**, **Relational Databases (MySQL)**, **Object-Relational Mapping (SQLAlchemy)**, **HTTP Networking**, and **JavaScript Fundamentals**.

---

## Curriculum & Directory Map

| Directory | Topic | Key Concepts |
| :--- | :--- | :--- |
| [0x00-python-hello_world](./0x00-python-hello_world) | Python Intro | Zen of Python, PEP 8, print formatting, string slicing, cycle detection in C |
| [0x01-python-if_else_loops_functions](./0x01-python-if_else_loops_functions) | Control Flow | Conditionals, while/for loops, functions, variable scopes, ASCII tables |
| [0x02-python-import_modules](./0x02-python-import_modules) | Modules & CLI | Importing modules, `sys.argv`, `__name__ == "__main__"`, building a calculator |
| [0x03-python-data_structures](./0x03-python-data_structures) | Data Structures | Lists, tuples, matrix operations, list comprehensions, palindrome linked list in C |
| [0x04-python-more_data_structures](./0x04-python-more_data_structures) | Sets & Dictionaries | Set operations, dictionary key-value mapping, lambda functions, `map`, `filter`, `reduce` |
| [0x05-python-exceptions](./0x05-python-exceptions) | Exceptions | Exception handling (`try`, `except`, `else`, `finally`, `raise`), writing safe functions |
| [0x06-python-classes](./0x06-python-classes) | OOP Basics | Object-Oriented Programming, classes, private attributes, getters/setters with `@property` |
| [0x07-python-test_driven_development](./0x07-python-test_driven_development) | TDD | Test-Driven Development using `doctest` and `unittest`, edge cases, docstrings |
| [0x08-python-more_classes](./0x08-python-more_classes) | Advanced OOP | Class attributes vs instance attributes, `__str__`, `__repr__`, `__del__`, class methods |
| [0x09-python-everything_is_object](./0x09-python-everything_is_object) | Object Model | Object references, `id()`, `type()`, mutability vs immutability, pass-by-assignment |
| [0x0A-python-inheritance](./0x0A-python-inheritance) | Inheritance | Class inheritance, method overriding, `super()`, `isinstance()`, `issubclass()` |
| [0x0B-python-input_output](./0x0B-python-input_output) | File I/O & JSON | Reading/writing files (`with open`), JSON serialization and deserialization (`json.dump/load`) |
| [0x0D-SQL_introduction](./0x0D-SQL_introduction) | MySQL Intro | Relational database basics, DDL (`CREATE`, `DROP`), DML (`SELECT`, `INSERT`, `UPDATE`, `DELETE`) |
| [0x0E-SQL_more_queries](./0x0E-SQL_more_queries) | Advanced SQL | Multi-table relational queries, `JOIN` (INNER, LEFT, RIGHT), subqueries, foreign keys |
| [0x0F-python-object_relational_mapping](./0x0F-python-object_relational_mapping) | ORM & MySQL | Connecting Python to MySQL with `MySQLdb` and `SQLAlchemy`, mapping classes to tables |
| [0x10-python-network_0](./0x10-python-network_0) | Network 0 (cURL) | HTTP requests with `curl`, HTTP methods (GET, POST, PUT, DELETE), header inspection |
| [0x11-python-network_1](./0x11-python-network_1) | Network 1 (Python) | Fetching internet resources via Python using `urllib` and `requests`, handling status codes |
| [0x12-javascript-warm_up](./0x12-javascript-warm_up) | JS Warm Up | JavaScript syntax, variable scopes (`var`, `let`, `const`), loops, functions, CLI args |
| [0x13-javascript_objects_scopes_closures](./0x13-javascript_objects_scopes_closures) | JS OOP & Closures | Classes, constructor functions, prototypes, closures, inheritance (`extends`, `super`) |
| [0x15-javascript-web_jquery](./0x15-javascript-web_jquery) | jQuery DOM & AJAX | DOM manipulation, styling, event listeners, and asynchronous HTTP GET/POST via jQuery |

## Requirements & Environment

- **Python**: Python 3.8.5 on Ubuntu 20.04 LTS, styled according to PEP 8 / `pycodestyle` (version 2.8.*).
- **MySQL**: MySQL 8.0 server and client.
- **Node.js**: Node.js 14.x+, styled with `semistandard`.
