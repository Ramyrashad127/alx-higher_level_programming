# 0x08. Python - More Classes and Objects

## Description
Advanced OOP concepts in Python: class attributes vs instance attributes, special dunder methods (__str__, __repr__, __del__), static methods (@staticmethod), and class methods (@classmethod).

## Learning Objectives
- Master higher-level language paradigms and architectural concepts.
- Follow PEP 8 style standards for Python and Semistandard for JavaScript.
- Build clean, modular, and testable code.
